# ConuAI-BOT

用于配置DeepseekAI到QQ app与人互动的BOT，并起名ConuAI-BOT，附带毛玻璃与仿ios效果，丝滑动效与背景鼠标跟踪效果！
作者 QQ：3789233492

功能：
1.高颜值前端              Vue3 + TailwindCSS制作，动画丝滑，背景与鼠标指针联动，按键拥有缓动效果，主打简约，ios美学
2.多个配置可供创建切换     支持在网页端创建多套配置，多套提示词 APIkey可随意切换
3.安全配置                支持违禁词拦截，一键拉黑、1分钟限流、群聊仅 @ 触发，（注：AI 触发警告词时，自动在后台生成违规记录，可一键私信警告）
4.表情包                  提示词写入图床URL可发送表情包，这个功能需要把提示词写好一点AI才看的懂建议附上“ 格式为[img:图片链接] ”这句话在相关提示词后
5.娱乐                   目前支持在QQ发送网易云音乐名片比如 用户：”@BOT 我想听MYGO的春日影“ bot就会给予用户相关音乐的网易云名片
6.日志与数据持久化        安全退出时自动保存每日 Token 消耗与日志，重启无缝衔接
7.拉黑后通知用户          可自定义回复词！

安装环境（必看）
  需安装[Python 3.8+](https://www.python.org/)
  部署 [NapCat](https://github.com/NapNeko/NapCatQQ) 并登录 QQ 账号。
  安装依赖，解压本项目后在本项目文件夹空白处，按住 `Shift` + 鼠标右键，选择“在此处打开 PowerShell 窗口”或“命令提示符”，输入以下命令安装依赖：
  ================================================================================================================================
      ```bash
      pip install aiohttp websockets psutil
  =================================================================================================================================

启动项目（必看）
  双击运行 启动.bat 即可。
  浏览器会自动打开 http://127.0.0.1:8080。
  如果双击闪退，请确保 Python 已加入系统环境变量。
配置 NapCat
  在 NapCat 的设置中，新建一个 WebSocket 客户端，连接地址填 ws://127.0.0.1:8081

目录结构
  首次运行后，程序会自动在根目录生成一个 rz 文件夹，用于存放所有的隐私配置与日志：
    ConuAI-BOT/
  ├── server.py              # 后端主程序
  ├── index.html             # 前端 Web 控制台
  ├── 启动.bat               # 一键启动脚本
  └── rz/                    # （自动生成）数据文件夹
      ├── config.json        # 当前生效的配置
      ├── profiles.json      # 所有配置方案的备份
      ├── temp_log_xxx.json  # 每日 Token 消耗日志
      └── archive_xxx.json   # 退出时的归档日志

请勿将本地生成的 rz 文件夹上传至公开网络，里面包含你的 API Key 等隐私信息。
本项目仅供编程学习交流使用，请勿用于违法用途！
